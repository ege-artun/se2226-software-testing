# Library-DB-Express test assets

Test files written for [Library-DB-Express](https://github.com/jlayher/Library-DB-Express) (by jlayher). The application itself is not included here.

| Folder | Content |
|--------|---------|
| `jest/` | `books.test.js` (48 Jest + Supertest tests) and the saved coverage output |
| `mutation/` | Stryker configuration and the saved console output (105 mutants, 60.19 % score) |
| `jmeter/` | JMeter test plan and screenshots of the 10-, 50- and 100-user runs |

See the [main README](../README.md#library-db-express--jest-stryker-and-jmeter) for step-by-step instructions on how to run them.
